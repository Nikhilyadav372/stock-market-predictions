## 1. Project Overview & Executive Summary

The **AI Stock Forecasting & Market Sentiment Analysis Platform** is an end-to-end, production-quality quantitative finance application. It combines traditional **Technical Analysis**, **Supervised Machine Learning (XGBoost & Deep Learning PyTorch models)**, and **Natural Language Processing (FinBERT NLP)** to forecast stock price movements and evaluate trading strategies.

### Key Capabilities:
- **Multi-Asset Market Tracking**: Tracks US Market stocks (`AAPL`, `MSFT`, `NVDA`, `TSLA`), Indian Market stocks (`TATAMOTORS.NS`, `RELIANCE.NS`, `TCS.NS`), Crypto (`BTC-USD`), and Market Indices (`^NSEI`).
- **Dual Prediction Tasks**: Performs **Price Target Regression** (predicting future dollars) and **Directional Classification** (predicting **UP** vs **DOWN**).
- **Explainable AI (XAI)**: Uses SHAP value attributions to break down why an AI model made a specific forecast.
- **Realistic Backtesting**: Simulates long-flat investment strategies on historical test splits without look-ahead bias.

## 4. Core Features & Feature Uses

### 4.1 Market Dashboard & Interactive Charts
- **Use**: Allows users to inspect any stock's current market state.
- **Details**: Displays current price, daily change ($ and %), 52-week high/low range, and trading volume. Interactive Recharts allow zooming into 1M, 3M, 6M, 1Y, and 5Y periods with hover tooltip inspections.

### 4.2 Technical Indicators Suite
- **Use**: Analyzes price momentum, volatility, and trend directions.
- **Indicators Calculated**:
  1. **RSI (14)**: Identifies Overbought (>70) and Oversold (<30) market states.
  2. **MACD (12, 26, 9)**: Signal line crossovers for trend reversal detection.
  3. **Moving Averages (SMA 5, 10, 20, 50, 200 & EMA 12, 26)**: Trend identification.
  4. **Bollinger Bands**: Upper, Lower, & Middle bands to gauge price volatility bands.
  5. **ATR (14)**: Average True Range measuring market volatility risk.

### 4.3 6 Multi-Model Machine Learning Engine
- **Use**: Generates predictive price forecasts and directional signals (**UP** vs **DOWN**).
- **Available Models**:
  1. **Naive Baseline**: Persistence model (today's price = tomorrow's price baseline).
  2. **Linear Model**: Ridge Regression / Regularized Logistic Classifier.
  3. **Random Forest**: Ensemble of decision trees reducing prediction variance.
  4. **XGBoost**: Extreme Gradient Boosting for high-accuracy tabular predictions.
  5. **LSTM (Long Short-Term Memory)**: PyTorch Recurrent Neural Network for temporal patterns.
  6. **GRU (Gated Recurrent Unit)**: Streamlined RNN variant for time-series data.

### 4.4 FinBERT Financial News Sentiment Engine
- **Use**: Quantifies news market mood to enhance price predictions.
- **Details**: Feeds financial news headlines into **ProsusAI/finbert**. Calculates probabilities for Positive, Neutral, and Negative sentiments and computes a **Compound Sentiment Score** (-1.0 to +1.0).

### 4.5 SHAP Prediction Explainability
- **Use**: Opens the "black box" of machine learning predictions.
- **Details**: Computes exact Shapley values showing which features (e.g., RSI spike, 5-day return lag, volume increase) pushed the model's prediction higher or lower.

### 4.6 Model Comparison Registry
- **Use**: Side-by-side performance comparison of all trained models.
- **Metrics Tracked**:
  - **Regression**: MAE (Mean Absolute Error), RMSE, R² Score, Directional Accuracy %.
  - **Classification**: Accuracy %, Precision, Recall, F1-Score, ROC-AUC.

### 4.7 Historical Backtesting Engine
- **Use**: Simulates how a trained model would have performed if traded in the past.
- **Details**: Uses a Directional Long-Flat strategy starting with \$10,000 capital. Outputs Cumulative Return %, Win Rate %, Max Drawdown %, Sharpe Ratio, and an Equity Curve graph.

## 5. Under-the-Hood Workflow

```
[Raw Stock Data] ──► [Feature Engineering] ──► [Chronological Split]
                                                    │ (70% Train / 15% Val / 15% Test)
                                                    ▼
[Inference / Forecast] ◄── [Save Artifact (.pkl)] ◄── [Train Model (XGBoost/LSTM)]
```

### 5.1 Data Ingestion & Caching
1. User requests stock data (`yfinance`).
2. Service checks raw CSV cache in `data/raw/{SYMBOL}.csv`.
3. If cache is missing/expired, fetches fresh data, validates columns, and saves cache.
4. If offline or rate-limited, automatically falls back to labeled demo sample data in `data/sample/`.

### 5.2 Feature Engineering (No Look-Ahead Leakage)
- Transforms raw OHLCV rows into 30+ lagged and calculated features.
- All technical indicators use strictly past data (e.g., `shift(1)` for return lags).

### 5.3 Time-Series Validation Split
- **Train (70%)**: Chronologically oldest data used to fit models and scalers.
- **Validation (15%)**: Hyperparameter tuning.
- **Test (15%)**: Chronologically newest data used strictly for unbiased final evaluation.
- *Scalers are fitted ONLY on the training split to prevent data leakage.*

### 5.4 Training & Inference Pipeline
1. Model training runs in asynchronous background workers.
2. Trained artifacts (model weights, feature column lists, fitted scalers) are saved in `./models/{model_id}.pkl`.
3. Inferences load the `.pkl` artifact, scale fresh input data, and generate multi-day horizon forecasts.

### 5.5 Backtest Strategy Simulation
- Starting Capital = \$10,000.
- Daily iteration:
  - If Model Prediction == `UP` ➔ Go Long (Capture next-day return).
  - If Model Prediction == `DOWN` ➔ Stay Flat (0% return, capital preserved).
- Computes Sharpe Ratio: $\text{Sharpe} = \frac{\text{Mean Daily Return}}{\text{Std Daily Return}} \times \sqrt{252}$.

## 6. Step-by-Step User Operating Guide

### Step 1: Open the Application
Navigate to **[http://localhost:5173](http://localhost:5173)** in your browser.

### Step 2: Search or Select Stock
- Click the **Stock Selector Dropdown** in the top bar.
- Choose popular tickers (`AAPL`, `MSFT`, `TATAMOTORS.NS`, `NVDA`, `RELIANCE.NS`) or type any custom ticker into the search box and press **Enter**.

### Step 3: Analyze Stock Technicals
- View real-time prices, 52W high/low, RSI, MACD, and Bollinger Bands on the **Dashboard** page.

### Step 4: Train an AI Model
- Navigate to **Forecast ➔ Train Model**.
- Select stock symbol, model algorithm (e.g., XGBoost or LSTM), task type (Regression or Classification), and feature set.
- Click **Start Training**.

### Step 5: Generate Predictions & Explainability
- Navigate to **Forecast ➔ Predict**.
- Select your trained model and choose a forecast horizon (1, 5, 10, or 20 periods).
- Click **Generate Forecast** to view future predictions and SHAP feature contributions.

### Step 6: Run Historical Backtest
- Navigate to **Backtesting**.
- Select your trained model and date range (e.g. past 6 months).
- Click **Run Backtest** to inspect Win Rate %, Cumulative Return %, Drawdown, and Equity Curve.
