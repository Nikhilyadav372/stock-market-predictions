## 1. Project Overview & Executive Summary

The **AI Stock Forecasting & Market Sentiment Analysis Platform** is an end-to-end, production-quality quantitative finance application. It combines traditional **Technical Analysis**, **Supervised Machine Learning (XGBoost & Deep Learning PyTorch models)**, and **Natural Language Processing (FinBERT NLP)** to forecast stock price movements and evaluate trading strategies.

## 4. Core Features & Feature Uses

### 4.1 Market Dashboard & Interactive Charts
- **Use**: Allows users to inspect any stock's current market state.
- **Details**: Displays current price, daily change ($ and %), 52-week high/low range, and trading volume. Interactive Recharts allow zooming into 1M, 3M, 6M, 1Y, and 5Y periods with hover tooltip inspections.

### 4.2 Technical Indicators Suite
- **Use**: Analyzes price momentum, volatility, and trend directions.
- **Indicators**: RSI (14), MACD (12, 26, 9), SMA (5, 10, 20, 50, 200), EMA (12, 26), Bollinger Bands, ATR (14).

### 4.3 6 Multi-Model Machine Learning Engine
- **Use**: Generates predictive price forecasts and directional signals (**UP** vs **DOWN**).
- **Models**: Naive Baseline, Linear Model, Random Forest, XGBoost, LSTM, GRU.

### 4.4 FinBERT Financial News Sentiment Engine
- **Use**: Quantifies news market mood.
- **Details**: Feeds financial headlines into **ProsusAI/finbert**, calculating Positive, Neutral, Negative sentiment probabilities and a Compound Sentiment Score (-1.0 to +1.0).

### 4.5 SHAP Prediction Explainability
- **Use**: Opens the "black box" of machine learning predictions using Shapley values.

### 4.6 Model Comparison Registry
- **Use**: Side-by-side performance comparison of all trained models (MAE, RMSE, R², Directional Accuracy %, F1-Score).

### 4.7 Historical Backtesting Engine
- **Use**: Simulates a Directional Long-Flat trading strategy starting with \$10,000 capital. Outputs Cumulative Return %, Win Rate %, Max Drawdown %, Sharpe Ratio, and Equity Curve graph.

## 5. Under-the-Hood Workflow

1. **Data Ingestion**: `yfinance` fetches daily OHLCV prices, cached in `data/raw/`.
2. **Feature Engineering**: Calculates 30+ technical indicator features and lags.
3. **Time-Series Split**: Chronological 70% Train, 15% Validation, 15% Test. Scalers fit ONLY on Train split.
4. **Training & Inference**: Asynchronous training workers save `.pkl` artifacts into `./models`.
5. **Backtesting**: Daily simulation calculating long-flat portfolio equity curve.

## 6. Step-by-Step User Operating Guide

1. **Open App**: Go to **[http://localhost:5173](http://localhost:5173)**.
2. **Select Stock**: Type any symbol (e.g. `TATAMOTORS.NS`, `AAPL`, `NVDA`) in the search box and press Enter.
3. **Analyze Technicals**: Inspect RSI, MACD, Moving Averages.
4. **Train Model**: Go to **Forecast ➔ Train Model**, pick algorithm, and click Start Training.
5. **Predict & Explain**: Go to **Forecast ➔ Predict** to generate forecasts & view SHAP values.
6. **Backtest**: Go to **Backtesting**, select model, choose date range, and click Run Backtest.

## 7. REST API Endpoint Reference

- `GET /api/health` — Health check
- `GET /api/stocks` — List stocks
- `GET /api/stocks/{symbol}/history` — Price history
- `GET /api/stocks/{symbol}/indicators` — Technical indicators
- `POST /api/data/refresh` — Refresh market data
- `POST /api/models/train` — Train ML model
- `POST /api/predict` — Generate forecast
- `GET /api/explain/{id}` — SHAP explainability
- `POST /api/sentiment/analyze` — FinBERT news sentiment
- `POST /api/backtest` — Run strategy backtest
